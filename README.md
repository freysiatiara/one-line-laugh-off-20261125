## Entry

`main.py` (Python, standard library only) writes exactly one funny line to
`/output/entry.txt`:

> I told my Roomba it was adopted; now it only cleans the rooms it likes and calls me by my first name.

## Run

```sh
python3 main.py
```

The output path can be overridden with the `ENTRY_OUTPUT` environment
variable, or `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR`.
